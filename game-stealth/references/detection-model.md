# 检测模型与警戒状态

> 具体距离、角度、时间阈值由项目规范给出；本表只定义结构与验证项。

## 1. 感官

| 感官 | 要定义 | 失败模式 |
|---|---|---|
| 视觉 | 距离、角度、遮挡、光照、伪装 | 球形触发器、隔墙看见 |
| 听觉 | 噪音源、半径、衰减、遮挡 | 全图听见、无消音 |
| 记忆 | 最后已知位置、记忆时长、共享 | 瞬间全图追踪 |
| 情报共享 | 谁和谁共享、延迟、范围 | 所有敌人共享一个大脑 |

## 2. 检测进度

- 二值检测：必须有可见预警（音效/图标/动作）。
- 渐进检测：进度条/颜色/动作；被遮挡/远离时衰减。
- 检测来源：视线中心 vs 边缘；移动 vs 静止；蹲伏/伪装。
- 调试：视锥、听觉半径、检测进度、最后已知位置。

## 3. 警戒状态机

| 状态 | 进入 | 行为 | 退出 |
|---|---|---|---|
| 平静 | 默认 | 巡逻/日常 | 发现线索 |
| 疑惑 | 线索/部分检测 | 调查局部 | 确认/放弃 |
| 搜索 | 目标丢失/确认 | 搜索最后位置 | 找到/超时 |
| 追击 | 确认目标 | 追捕/呼叫 | 抓到/失去 |
| 丢失 | 追击失败 | 回到搜索 | 超时/再发现 |

检查：

- 升级/降级都有条件
- 追击有脱战条件
- 状态变化可读（图标/音效/动作）
- 共享情报有范围/延迟
- 不会因为一次失误永久锁定

## 4. 验证矩阵

| 用例 | 期望 |
|---|---|
| 正面远距离 | 不发现 |
| 侧面近距离 | 逐渐发现 |
| 隔墙/掩体 | 不发现/丢失 |
| 蹲伏/慢走 | 检测变慢 |
| 噪音源 | 调查噪音点 |
| 丢失目标 | 搜索最后位置，不瞬间全图 |
| 脱战 | 回到搜索/平静 |

证据：固定场景断言 + 调试绘制 + 录屏/试玩。
