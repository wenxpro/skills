# 潜行与风险设计

目标：让玩家在「拿更多」与「更安全」之间真的犹豫，而不是把潜行做成「蹲下就隐身」。

本 skill 负责玩家潜行循环、检测与风险经济；敌人 AI 的感知/决策用 `game-ai-design`，关卡布局用 `level-encounter-design`，战斗数值用 `game-combat-model`。

## 何时使用

- 设计潜行、劫掠、偷窃、追逃、非对称生存
- 有「被发现」状态、视野/听觉、遮挡、噪音、警戒等级
- 想用风险资源（重量、热量、时间、战利品）制造取舍
- 排查「敌人太神/太瞎」「被发现就必死」「潜行没有选择」

不适用：

- 普通敌人 AI 的目标选择/难度调参 → `game-ai-design`
- 战斗伤害、TTK、克制 → `game-combat-model`
- 关卡路线、掩体、巡逻点布局 → `level-encounter-design`
- 剧情/对白/世界观 → `narrative-docs`

## 行为

参考型 skill，无主动打断。用户要求设计/审计潜行或风险循环时使用。

## 核心规则

### 1. 先定义潜行的承诺

- 玩家是在「避免战斗」还是「选择战斗时机」？
- 失败是被抓、被杀、失去战利品，还是强制进入战斗？
- 潜行是否可恢复？一次失误是否直接终局？
- 没有明确承诺，检测和警戒状态就没有设计目标。

### 2. 检测模型要可解释

- 感官：视觉、听觉、记忆/最后已知位置；是否共享情报。
- 视觉：距离、角度、遮挡、光照/伪装；不要只用一个球形触发器。
- 听觉：脚步、噪音源、传播衰减；是否有消音手段。
- 记忆：失去目标后搜索最后位置，不瞬间全图追踪。
- 检测是渐进的还是二值的？二值必须有明确预警。
- 调试可视化：视锥、听觉半径、警戒状态、最后已知位置。

### 3. 警戒状态机

| 状态 | 职责 | 退出 |
|---|---|---|
| 平静 | 巡逻/日常 | 发现线索 |
| 疑惑 | 调查局部 | 确认/放弃 |
| 搜索 | 搜索最后已知位置 | 找到/超时 |
| 追击 | 直接追捕 | 抓到/失去 |
| 丢失 | 回到搜索/平静 | 超时/再发现 |

- 升级与降级都要有；不能只升不降。
- 状态变化要可读：图标、音效、动作、台词；颜色不是唯一信息。
- 敌人不能共享全图情报，除非有明确通讯设定。
- 追击要有脱战条件，避免无限追杀。

### 4. 潜行手段要有反制

- 蹲伏/慢走、掩体、阴影、噪音控制、 distraction、伪装、同伴、道具。
- 每种手段至少有一个成本/反制；没有反制的手段会变成唯一解。
- 手段之间要有取舍：更快但更吵、更安全但更慢、更强但更显眼。
- 不要让一种手段同时解决所有检测维度。

### 5. 风险资源

- 风险资源可以是重量、战利品、热量、时间、警戒值、同伴安全。
- 资源增加收益，但降低机动/提高检测/延长暴露；必须真的影响决策。
- 不要把风险资源做成第二条血条；它应该改变「继续还是撤」。
- 收益与风险的曲线要可感知：玩家能在几秒内判断「再拿一件值不值」。
- 失败惩罚要可恢复；一次贪心不应直接抹掉整局，除非是明确的硬核规则。

### 6. 追逃与失败恢复

- 被发现后玩家还有什么选择：逃、藏、丢资源、反击、求饶、同伴救援。
- 脱战条件写清楚：距离、时间、遮挡、丢失最后位置。
- 失败后的重开时间要短；保留学习信息（为什么被发现）。
- 不要用「被抓即结束」掩盖检测/关卡问题。

### 7. 可读性

- 玩家能看懂：谁在看我、看到什么程度、下一步会怎样。
- 视野锥/警戒图标/音效/动作至少两路可辨。
- 灰度/静音下仍能判断危险。
- 调试面板显示：状态、最后已知位置、检测进度、风险资源。

### 8. 关卡依赖

- 掩体、光照、噪音源、巡逻路线、逃生路线是潜行设计的一部分。
- 关卡布局交 `level-encounter-design`；本 skill 只给需求（需要哪些掩体/视线/逃生口）。
- 没有关卡支撑的检测参数只是数字；要用地图验证。

### 9. 证据

- 检测矩阵：距离/角度/遮挡/噪音/状态转换。
- 固定场景断言：视锥、听觉、最后已知位置、脱战。
- 录屏/试玩：玩家是否看懂、是否真的犹豫。
- 静态截图只能证明可读性，不能证明追逃节奏。

## 检查清单

- [ ] 潜行承诺清楚：避免战斗还是选择时机？失败是什么？
- [ ] 视觉/听觉/记忆/共享情报规则明确
- [ ] 警戒状态有升级与降级，追击有脱战
- [ ] 潜行手段各有成本/反制，没有唯一解
- [ ] 风险资源真的改变「继续/撤退」决策
- [ ] 被发现后仍有选择，不是必死
- [ ] 状态/视锥/风险可读，灰度/静音可辨
- [ ] 关卡有掩体/光照/噪音/逃生路线支撑
- [ ] 检测/追逃有固定场景断言与录屏
- [ ] 没有把「蹲下=隐身」当成潜行

## 反模式

- 敌人全图共享情报、瞬间锁定
- 二值检测没有预警，发现即必死
- 蹲下就隐身，没有视线/噪音/光照
- 只有一种潜行手段，或一种手段解决所有问题
- 风险资源不影响决策，只是第二条血条
- 被发现后没有逃/藏/丢资源的选择
- 只用截图证明潜行好玩
- 关卡没有掩体/逃生路线，却怪 AI 太强

## 边界

- 不写具体项目的视野角度、距离、风险值、战利品重量
- 不替代敌人 AI、关卡布局、战斗数值
- 不把「硬核即有趣」当默认；失败惩罚要可解释
- 潜行/追逃的连续观感必须真人试玩验证
