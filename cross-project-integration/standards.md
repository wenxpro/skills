# 跨项目协作偏好

> 本文件是可替换的团队偏好；通用规则在 `SKILL.md`。项目有自己的规范时，以项目规范为准。

## 1. 编号

| 项 | 约定 |
|---|---|
| 接口 ID | `<capability>.<interface>` 或 `IF-<序号>` |
| 版本 | 主版本.次版本；不兼容变化升主版本 |
| 工作流 ID | `<project>-<workstream>` |
| 证据 ID | `<date>-<capability>-<version>` |

## 2. 冻结点

| 阶段 | 冻结什么 | 谁批准 |
|---|---|---|
| 设计出口 | 上下游、接口字段、错误语义 | `<owner>` |
| 并行前 | 共享文件/资源、接口版本 | `<owner>` |
| 集成前 | 迁移方式、回滚条件 | `<owner>` |
| 切换前 | parity 证据、默认路径 | `<owner>` |

没有冻结点，不进入并行；没有集成 owner，不进入合并。

## 3. 集成节奏

- 集成窗口：`<cadence>`（例如每周一次）。
- 每次集成至少检查：接口版本、生产者检查、消费者检查、端到端样本。
- 失败处理：停止合并、保留证据、回到接口登记表定位。
- 不在集成窗口外做默认路径切换。

## 4. 证据位置

| 证据 | 位置 |
|---|---|
| 接口登记表 | `<path>` |
| 依赖矩阵 | `<path>` |
| 集成计划 | `<path>` |
| 样本 / fixture | `<path>` |
| 报告 / 日志 | `<path>` |
| 跨项目交接 | `<path>` |

## 5. 角色

| 角色 | 职责 |
|---|---|
| 上游 owner | 接口、版本、兼容、生产者检查 |
| 下游 owner | 适配层、语义校验、消费者检查 |
| 集成 owner | 顺序、冻结点、集成检查、切换/回滚 |
| 执行者 | 有界任务、写集、完成标准、证据 |
| 决策人 | 范围、取舍、默认路径切换 |

## 6. 模板覆盖

- 接口登记表：`templates/interface-register.md`
- 依赖矩阵：`templates/dependency-matrix.md`
- 集成计划：`templates/integration-plan.md`
- 跨项目交接：`templates/cross-repo-handoff.md`

项目可以替换模板，但至少保留：owner、版本、冻结点、检查、证据、回滚。
