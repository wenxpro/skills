## 3. 读图结论

| 模式 | 发现 | 动作 |
|---|---|---|
| 密集列（共享热点） | `<element>` | 先冻结 / 指定唯一 owner |
| 循环 | `<A → B → A>` | 拆接口 / 先做决策 / 调整顺序 |
| 空行/空列 | `<element>` | 可并行 |
| 块 | `<elements>` | 作为一个工作包/模块 |
| 共享文件 | `<path>` | 单一写者 / 冻结窗口 |
