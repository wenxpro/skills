# 体验架构标准与偏好

> 这是个人/团队偏好文件。其他团队可以整体替换，不需要改 `SKILL.md`。

## 表面命名

| 类型 | 含义 | 例子 |
|---|---|---|
| Screen | 独立屏幕，切换时替换主内容 | 首页、设置、结果 |
| Overlay | 覆盖在当前屏幕上的临时层 | 暂停、确认框、升级选择 |
| Mode | 一套完整的玩法/任务循环 | 标准局、挑战局、试炼 |
| System page | 平台/系统级页面 | 登录、存档、错误页 |

- 一个模式至少包含 Setup、Run、Result 三个表面；没有 Result 的模式不算闭环。
- 一个屏幕只能有一个主要返回目标；不要按来源不同返回不同地方，除非状态显式记录。

## 导航默认值

- 一个根入口；最多两层：根 → 分类 → 详情。
- Esc/Back：详情回分类，分类回根；覆盖层关闭回上一层；局内暂停回继续。
- 不把模式选择、难度选择、种子设置塞进局内 READY。
- 不用「Home → Play → Mode → Difficulty → Confirm → Ready」的深菜单。
- 入口卡片优先于下拉菜单；主按钮只有一个。

## 状态所有权

| 状态 | 拥有者 | 生命周期 | 典型内容 |
|---|---|---|---|
| Product state | 外壳/导航 | 应用级 | 当前屏幕、导航栈、全局弹窗 |
| Session state | 会话/用户 | 登录或本次启动 | 用户偏好、最近配置、解锁 |
| Run state | 局内/任务 | 单局 | 计时、分数、局内状态机 |
| Persistent state | 存档/配置 | 跨启动 | 设置、进度、统计 |

规则：

- 产品状态不能塞进局内状态机。
- 局内状态机不能决定外壳导航。
- 持久状态必须有版本、迁移、损坏回退。
- 单局重开只清 Run state，不清 Session/Persistent。

## 生命周期

每个表面写清：

| 阶段 | 要回答 |
|---|---|
| Create | 谁创建、依赖什么 |
| Load | 加载哪些数据、失败怎么办 |
| Activate | 进入时刷新什么 |
| Pause | 暂停谁、谁继续跑 |
| Resume | 恢复时重算/重载什么 |
| Teardown | 释放什么、取消哪些订阅 |

- 重开/返回必须明确清理：节点、定时器、信号、缓存、临时输入。
- 暂停作用域必须写成一句话；不要依赖「整棵树暂停」。

## 输入与焦点

- 键盘/鼠标先做；焦点顺序为手柄预留。
- 菜单打开时，局内输入必须隔离；关闭后恢复。
- Esc/Back 在所有表面行为一致；不要只在某些页面响应。
- 焦点不能落到不可见/禁用控件；覆盖层关闭后焦点回到触发点。

## 延后项格式

```text
Surface | Why deferred | Trigger | Cost | Owner
```

- 没有触发条件的延后项不算延后，算遗漏。
- 触发条件必须是可观察事件：新增模式、第二个入口、持久设置、平台壳层、试玩反馈等。
- 成本用相对量级（小/中/大）或天数区间，不写虚假精确值。

## 评审角色

| 角色 | 只问一个问题 |
|---|---|
| 新用户 | 能不能找到开始，并知道怎么退出？ |
| 回访用户 | 能不能用最少的操作继续上次/重开？ |
| UX | 返回、暂停、焦点是否一致？ |
| 技术负责人 | 状态所有权和暂停作用域是否清楚？ |
| QA | 每个表面、每条边是否可测试、可清理？ |

## Profile：游戏

- 典型表面：Home、Run Setup、Run、Pause、Result、Settings、图鉴、试炼。
- Product state：当前屏幕/导航栈；Run state：局内状态机。
- 暂停：外壳/菜单保持响应；只暂停局内子树，或显式列出暂停组。
- 死亡/胜利：Result 必须提供同配置 Retry、换配置、回 Home。
- 图鉴/试炼是独立屏幕，不塞进局内暂停或 READY。

## Profile：应用

- 典型表面：登录、工作区、详情、设置、个人资料。
- Product state：路由/导航；Session state：登录态与用户偏好。
- 深链接、刷新、权限失败必须有明确落点。
- 设置/保存失败不能把用户困在死页。

## 反模式

- 功能文档很全，但没有一页产品表面拓扑。
- UI 等于 HUD；没有 Home/Setup/Result/Pause 的归属。
- READY 或单页同时承担菜单、模式选择、重开提示。
- 菜单和业务在同一棵树里，整棵树暂停导致菜单冻结。
- 屏幕只能进不能出，或返回目标随来源变化。
- 延后壳层但不写触发条件。
- 为未来所有模式提前做完整页面。
- 用视觉稿代替状态所有权和生命周期。
