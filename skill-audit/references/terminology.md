# 术语表与废弃词扫描

> 本文件是 skills 仓库的术语规范。项目文档有自己的术语表时，以项目术语表为准；本文件不替代项目领域词。

## 规范术语

| 概念 | 规范说法 | 不要写 | 备注 |
|---|---|---|---|
| 行为规则 / 文档槽位 | 规则、行为规则 | 契约 | 代码接口用「接口约定」；执行流程用「执行约定」 |
| 合并前检查 | 合并前检查、必须跑的检查 | 变更门禁、门禁 | 具体检查项由项目规范定义 |
| 问题级别 | 必须修 / 建议修 / 可选 | 阻断 / 重要 / 建议（作为级别名） | P0/P1 只表示验收优先级；日常用语不受限 |
| 阈值参考值 | 基准值 | 基线（阈值/平衡语境） | 重构/性能「基线」可保留 |
| 执行流程约定 | 执行约定 | 执行契约 | 模板文件名 `execution-contract.md` 可保留 |

## 扫描种子

```sh
grep -rnE '契约|门禁|阻断' --include='*.md' --exclude-dir=.git .
```

允许出现旧词的情况：

- 本文件的「不要写」列
- 明确标注的迁移说明，如「旧词：契约 → 新词：规则」
- 引用历史原文，且上下文标明「原文」

其他命中一律替换。

## 判定顺序

1. 先判断是不是在引用旧词/历史原文；是则保留并标注。
2. 不是则按上表替换；同一概念只保留一种说法。
3. `基线` 只在阈值/平衡语境替换为「基准值」；重构/性能基线不强制。
4. 替换后跑 `scripts/check-skills.sh`，零命中才算完成。

## 与 docs-audit 的分工

- 本文件管 **skills 仓库内部**的术语一致性（规则 / 合并前检查 / 必须修 / 基准值）。
- `docs-audit` 管项目文档的翻译腔、自然表达和项目自己的术语表；它引用本文件时不重复维护词表。
