# 战斗模型审计清单

> 用于设计评审或验证阶段审计；具体数值写项目文档。

## 1. 角色差异

- 两个单位是否只有伤害/HP 不同？
- 攻击频率是否完全一样？如果一样，是否是有意设计？
- 速度/射程/机动/成本/风险是否至少有一个在测试中起作用？
- 去掉克制后，两个单位是否仍有不同打法？
- 如果只看单位剪影/攻击节奏，能否描述出不同角色？

## 2. 攻击时间轴

- 是否有前摇、命中帧、后摇、等待？
- 伤害是否只在命中帧结算？
- `attack_interval` 是否是完整周期？
- 双方是否每轮同帧出手？首次偏移是否设置？
- 动画（或占位 VFX）是否对齐命中帧？

## 3. 数值与目标

- 目标 TTK 是多少？目标命中数是多少？
- 有效 DPS 是否计算了护甲/克制？
- 胜者剩余 HP/资源目标是多少？
- 是否有镜像、克制、反向、混编对局？
- 是否存在支配性单位或必选单位？

## 4. 克制与反事实

- 克制倍率/预算是多少？
- 把克制设为 1.0 后，结果是否翻转或明显变化？
- 如果不变，克制是否只是装饰？
- 如果翻转太剧烈，是否变成“选对兵种就赢”？

## 5. 模拟与证据

- 是否固定 tick、初始布局、随机种子？
- 是否输出 TTK、命中数、剩余 HP/资源、关键时间点？
- 调参表是否与运行时配置一致？
- 结论是否只上升到证据支持的层级？
- 1v1 结果是否被误用为 2v2/决策空间结论？

## 6. 常见失败模式

| 现象 | 可能原因 | 修复方向 |
|---|---|---|
| 两个兵种打起来只比攻击力 | 同频率、同射程、同编制 | 拉开至少两个角色轴 |
| 克制存在但不影响结果 | 倍率太小/被护甲吃掉 | 重新定克制预算，做反事实 |
| 对局像节拍器 | 同帧出手、无前摇/后摇 | 攻击时间轴 + 首次偏移 |
| 数值调来调去不稳定 | 没有目标 TTK/命中数 | 先定目标再调参 |
| 1v1 赢了但 2v2 不好玩 | 1v1 只验证参数 | 用 2v2/地图/真人验证决策 |
