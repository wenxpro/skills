# 游戏战斗模型

目标：设计一个能产生**角色差异与可解释结果**的战斗模型，而不是“谁攻击力/HP 更高”的数值竞赛。

本 skill 只管战斗模型本身；验证计划用 `validation-design`，Spec/验收写作用 `game-docs`，动画/VFX 不在范围内。

## 何时使用

- 设计兵种、武器、技能、伤害公式、攻击节奏、克制关系
- 审计现有战斗模型是否只是数值竞赛
- 设定 TTK、命中数、克制预算、对决矩阵
- 搭建确定性战斗模拟与调参表
- 判断 1v1 结果能证明什么、不能证明什么

不适用：

- 动画、骨骼、VFX、镜头表现
- 单个数值微调，没有模型问题
- 网络同步/回放确定性（另用专门方案）
- 完整 GDD / 验收矩阵（`game-docs`）

## 行为

无主动打断。用户要求设计/审计战斗模型时使用；不主动评价日常动画或单次数值调整。

## 核心规则

### 1. 角色差异化至少两轴

可用轴：

- 攻击节奏（快/慢）
- 单次伤害 / DPS
- 射程 / 接战距离
- 机动 / 转向 / 加速
- 生存（HP / 护甲 / 减伤）
- 成本 / 人口 / 出场时机
- 风险（近身、蓄力、侧后）
- 克制 / 反制
- 编队 / 阵型 / 地形

**判据：** 如果两个单位只有“伤害/HP”不同，模型就是数值竞赛。至少两个轴要产生不同打法；否则重做角色定位。

### 2. 攻击是时间轴，不是一个冷却数字

```text
前摇 wind-up → 命中 hit → 后摇 recovery → 等待 idle → 下一次
```

- 伤害只在命中帧结算。
- `attack_interval` 是完整周期，不是“后摇后再加冷却”。
- 不同单位可以有不同的前摇/后摇/首次偏移；不要让双方每轮同帧出手。
- 动画可以后补，但命中帧必须先定；否则表现和规则对不上。

### 3. 先定 TTK / 命中数，再调伤害

- 目标 TTK（时间）与目标命中数（次数）是设计输入，不是结果。
- 先写目标区间，再用伤害/HP/频率去满足；不要先改伤害再看感觉。
- 记录有效 DPS：`(伤害 × 克制 - 护甲) / 周期`，以及击杀所需命中数。

### 4. 克制要有预算，不只是一个倍率

- 克制应该显著改变结果，而不是只让数字变大。
- **反事实检查：** 把克制设为 1.0，结果是否翻转或明显变化？不变，克制可能只是装饰。
- 克制太强会让对局变成“选对兵种就赢”；太弱则没有选择意义。用胜者剩余 HP/资源定义预算。

### 5. 对决矩阵与支配性检查

至少覆盖：

| 对局 | 目的 |
|---|---|
| A vs A（镜像） | 检查对称性/先手优势 |
| A vs B（克制） | 检查克制预算 |
| B vs A（反向） | 检查不是单向脚本 |
| 混编/多单位 | 检查组合是否产生新问题 |

- 如果某单位在所有对局都不劣，检查支配性。
- 如果某单位只在“玩家操作更好”时赢，检查操作上限是否合理。

### 6. 确定性模拟与调参表

- 固定 tick、固定初始布局、固定随机种子（如无随机则声明）。
- 输出：结果、TTK、命中数、双方剩余 HP/资源、关键时间点。
- 调参表列：单位、HP、护甲、周期、前摇、后摇、伤害、射程、速度、克制、目标 TTK、实测 TTK。
- 先跑模拟，再开 GUI 看表现；不要用截图猜数值。

### 7. 范围声明

- **1v1 自动对砍**只能验证参数与攻击时间轴，不能验证走位、抢点、组合、地形。
- 决策空间必须用 2v2/多单位/地图/真人试玩验证。
- 任何“战斗模型成立”的结论都要写清证据层级。

## 审计清单

- [ ] 两个单位是否只有伤害/HP 不同？
- [ ] 攻击频率是否完全一样？如果一样，是设计意图还是遗漏？
- [ ] 去掉克制后结果是否翻转/明显变化？
- [ ] 速度/射程/机动是否在测试中真正起作用？
- [ ] 伤害是否在命中帧结算？
- [ ] TTK/命中数是否有目标区间？
- [ ] 是否有镜像、反向、混编对局？
- [ ] 是否有支配性单位？
- [ ] 模拟是否可复现？调参表是否与运行时配置一致？
- [ ] 结论是否超出了 1v1 能证明的范围？

详细审计问题见 `references/model-audit.md`。

## 输出

- 战斗模型表：`templates/combat-model.md`
- 审计报告：发现 / 严重度 / 证据 / 行动项
- 验证计划：交给 `validation-design`

## 反模式

- 同频率 + 不同伤害 = 数值竞赛
- 克制是唯一差异，去掉后结果不变
- 速度/射程/机动在自动对砍里完全没用，却声称模型已验证
- 先调伤害，再补 TTK 目标
- 瞬伤 + 冷却，没有前摇/命中/后摇
- 用 1v1 结果证明 2v2 决策成立
- 只记录胜者，不记录 TTK/剩余 HP/命中数
- 用随机暴击掩盖模型差异不足
