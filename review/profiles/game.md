# Profile — Game

## 角色

| 角色 | 关注点 | 否决权 |
|---|---|---|
| 目标玩家 | 易懂、想再来一局、反馈是否成立 | 体验不成立 |
| 游戏设计师 | 循环、选择、节奏、构筑 | 核心玩法不成立 |
| 技术负责人 | 可行性、性能、维护 | 技术不可行 |
| 美术 / UX | 可读性、表现成本、信息层级 | 画面不可读 |
| 制作人 | 范围、时间、砍线 | 超范围 |
| QA | 可测试性、边界、回归 | 验收不足 |

## 必问

1. 玩家 30 秒内知道要做什么吗？
2. 这一局和上一局有什么不同？
3. 5 分钟后是否愿意重开？
4. 哪个升级/敌人/机制最难解释？
5. 40/60 敌人时是否可读、可跑？
6. P0 规则是否都有验收？

## 证据

- Run Brief
- Design Spec
- Acceptance
- ADR
- 试玩记录
- 性能 / 回归 JSON

## 文档

游戏文档本身由 `game-docs` skill 维护；本 profile 只负责角色与否决规则。
