# Profile — Narrative

用于长篇小说、电影/剧集剧本、视觉小说、叙事游戏的故事评审。它审“故事是否成立、读者是否理解与投入”，不审软件实现或玩法数值。

## 角色

| 角色 | 关注点 | 否决权 |
|---|---|---|
| 目标读者 / 观众 | 是否理解、是否想继续、情绪是否成立 | 读不下去 / 承诺不成立 |
| 故事编辑 | 前提、结构、场景转折、因果、人物弧线 | 故事逻辑不成立 |
| 连续性编辑 | 时间线、称谓、物件、知识状态、分支 flag | 连续性断裂 / 死局 |
| 台词 / 语气编辑 | 叙述声音、角色台词差异、潜台词 | 人物声音不可区分 |
| 制作 / QA（如适用） | 分支收敛、内容成本、可制作性 | 无法收敛 / 成本失控 |
| 作者 / 决策人 | 取舍、风格、最终拍板 | 最终决定 |

## 必问

1. 前 10% 是否建立故事承诺？读者能否说出主角想要什么？
2. 主角的动机是否成立？为什么是现在行动？
3. 每场是否有转折、选择或后果？删掉会少什么？
4. 人物“知道/不知道什么”是否自洽？有没有作者视角泄漏？
5. 遮住人名，能否分辨说话者？
6. 情绪节点是否有铺垫与回收？
7. 分支是否收敛？有没有无提示死局？
8. 哪些段落可以删而不影响承诺？
9. 证据来自自读、编辑还是目标读者？是否用低层证据代替高层结论？
10. 哪些问题是结构问题，哪些只是文字问题？

## 证据

- Story Brief
- World Bible
- Character Bible
- Structure / Scene Cards
- Voice Guide
- Continuity
- Read-through 记录
- Revision Log（`12-revision-log.md`）
- ADR
