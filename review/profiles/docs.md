# Profile — Docs

## 角色

| 角色 | 关注点 | 否决权 |
|---|---|---|
| 目标读者 | 能否看懂、能否完成任务 | 不可理解 |
| 领域专家 | 内容是否正确、边界是否完整 | 事实错误 |
| 技术写作 | 结构、术语、示例、可维护性 | 结构不可维护 |
| 维护者 | 更新成本、链接、版本 | 无法维护 |
| PM | 范围、优先级、交付时间 | 超范围 |
| QA | 示例可复现、检查脚本 | 无法验证 |

## 必问

1. 读者是谁、读完后能做什么？
2. 术语是否统一？
3. 示例是否可运行/可复现？
4. 哪些内容属于当前版本，哪些是未来？
5. 链接、编号、状态是否一致？
6. `check-docs.ps1` / `docs-audit` 是否通过？

## 证据

- 文档集
- 链接检查
- 示例输出
- 自检清单
