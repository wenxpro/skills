# 数据检查

回答：谁拥有数据，怎么查，怎么保持一致，怎么迁移与删除。

| 数据 | Owner | 写入方 | 读取方 | 生命周期 |

|  |  |  |  |  |

规则：

- 一份数据只有一个写入方。
- 其他服务通过接口或只读投影访问，不直接写表。
- 缓存不是事实源；写清失效与重建。

## 5. 迁移

推荐顺序：

1. expand：加新结构，双写/双读
2. migrate：回填与校验
3. contract：切读、删旧结构

检查：

- 是否锁表/停机？
- 是否可回滚？
- 回填如何限速？
- 如何校验新旧一致？
- 失败时停在哪一步？
