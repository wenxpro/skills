# 架构检查

回答：系统边界在哪，谁依赖谁，部署在哪，坏掉时影响多大。

## 1. 上下文与边界

- 系统负责什么、不负责什么？
- 外部参与者/系统有哪些？
- 哪些状态由本系统拥有，哪些只是缓存或投影？
- 哪些依赖是同步的，哪些是异步的？

- 组件是否按职责划分，而不是按文件类型划分？
- 是否存在双向依赖？
- 是否有一个组件同时承担规则、编排和展示？
- 状态是否只有一个写入方？
