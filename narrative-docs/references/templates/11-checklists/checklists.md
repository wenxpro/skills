# 检查清单

## 1. 初始化

- [ ] 目标目录已确认；已有 `docs/` 未被无提示覆盖
- [ ] `00-README.md` 有一句话、形式、当前阶段
- [ ] `01-story-brief.md` 一页内说清故事
- [ ] 关键方向（POV / 结局 / 分支模型 / 形式）有 ADR 或明确待定
- [ ] 未确认 01 前，没有提前写 02~07

## 2. Story Brief

- [ ] 一句话包含：谁想要什么、阻碍、代价
- [ ] 主题是问题，不是结论
- [ ] 读者承诺 ≤ 3 条
- [ ] 本阶段做 / 不做写清
- [ ] 读者体验判据可观察
- [ ] 止损条件可观察

## 3. 场景卡

- [ ] 每场有目标、阻碍、转折、后果
- [ ] 删掉这场，故事确实少了东西
- [ ] 选择改变信息、关系或代价之一
- [ ] 连续性引用已填（设定 / 人物知识 / 物件 / flag）
- [ ] 没有把正文片段塞进卡片

## 4. 连续性审计

- [ ] 时间线没有倒置或缺失
- [ ] 称谓与场合一致
- [ ] 人物不知道作者知道的信息
- [ ] 物件位置/状态有变化记录
- [ ] 伏笔有埋设与回收计划
- [ ] 冲突记录没有未解决的 P0 项
- [ ] 分支 flag 有触发与清除条件

## 5. 试读前

- [ ] 版本号/范围已记录
- [ ] 没有未解决的 P0 连续性问题
- [ ] 试读问题准备好（不解释、不辩护）
- [ ] 记录模板就位
- [ ] 分支剧本准备好路线记录方式

## 6. 修订

- [ ] 修订记录有版本、来源、问题、改动、影响文件
- [ ] 先修 P0，再做润色
- [ ] 改动已回写场景卡 / 连续性 / 人物知识状态 / 分支表
- [ ] 受影响场景已重新试读
- [ ] 不可逆叙事决定有 ADR

## 7. 变更与维护

- [ ] 影响面已列出（场景 / 人物 / 连续性 / 分支 / 承诺）
- [ ] 规则文档先改，正文后改
- [ ] 旧设定已标 `retired`，没有留在 canon
- [ ] 试读判据随承诺变化更新
- [ ] 文档状态与当前阶段一致

## 8. 阶段完成（DoD）

- [ ] 本阶段 P0 判据有证据
- [ ] 连续性无未解决 P0 冲突
- [ ] 修订记录与文档一致
- [ ] 试读记录有原话与行动项
- [ ] 未决项有 owner 与下一步
