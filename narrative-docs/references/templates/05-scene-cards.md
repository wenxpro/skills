# 05 · Scene Cards

> 一场一卡。只写工作信息，不写正文。正文另存。

## 场景卡模板

### S-XXX · <场景标题>

| 项 | 内容 |
|---|---|
| 所属 | <幕 / 序列> |
| 目的 | <这场在故事里完成什么> |
| 视角 | <POV> |
| 地点 / 时间 | <...> |
| 出场人物 | <C-001, C-002> |
| 目标 | <谁想要什么> |
| 阻碍 | <...> |
| 转折 | <...> |
| 揭示 | <给读者/人物什么信息> |
| 选择 | <如果有；选项与代价> |
| 后果 | <选择之后留下什么> |
| 连续性引用 | <W-001, C-003 知识状态, flag> |
| 预计长度 | <字 / 分钟> |
| 状态 | ◻ / 🔄 / ✅ |

#### 备注

- 这场如果删掉，故事少了：<...>
- 需要新设定 / 新人物：<...>
- 风险：<...>

---

## 使用规则

- 每场至少一个转折；没有转折就合并或删。
- 一场只完成一个主要目的；次要目的放备注。
- 选择必须改变信息、关系或代价；只换台词的选择标为“装饰”。
- 写完正文后回填“状态”和连续性引用，不另建一份台账。
