## 2. 阅读顺序

1. 先读 `01-story-brief.md`：故事是什么、对谁承诺什么。
2. 再读 `04-structure.md`：整体节奏与场景顺序。
3. 写到哪一场，读对应的 `05-scene-cards.md` 与 `07-continuity.md`。
4. 试读前读 `08-readthrough.md` 的判据。

## 4. 规则

- `canon` 只写已确定事实；未定想法标 `assumption`。
- 正文与文档分离：文档写工作信息，正文写最终表达。
- 一个事实一个位置：世界观规则在 02，人物事实在 03，时间/称谓/物件在 07。
- 改动后更新受影响文档；不可逆叙事决定写 ADR。
