# 08 · Read-through

> 这是读者体验的“验收”，不是软件 AC。判定的是读者是否理解、投入、相信，以及分支是否收敛。

## 1. 试读目标

- 验证故事承诺：<...>
- 验证理解：读者能否复述前提、主角动机、核心冲突。
- 验证情绪：关键节点是否有铺垫与回收。
- 验证 agency：选择/行动是否改变信息、关系或代价。
- 验证连续性：称谓、时间、知识状态是否自洽。
- 验证分支（如适用）：是否收敛、是否有死局。

## 2. 判据

| ID | 判据 | 级别 | 可观察证据 | 失败信号 |
|---|---|---|---|---|
| R-01 | 前提可理解 | P0 | 读者能用自己的话复述一句话故事 | 复述成另一个故事 |
| R-02 | 动机成立 | P0 | 读者能说出主角想要什么、为什么现在行动 | 只说“剧情需要” |
| R-03 | 场景有转折 | P0 | 读者能指出每场的变化 | 场景只是信息说明 |
| R-04 | 选择有后果 | P1 | 读者能说出选择改变了什么 | 只换台词/数值 |
| R-05 | 情绪有铺垫/回收 | P1 | 读者能指出铺垫与回收的位置 | 情绪突然出现 |
| R-06 | 连续性自洽 | P0 | 称谓/时间/知识状态无未解释冲突 | 读者发现矛盾 |
| R-07 | 分支收敛 | P0（分支剧本） | 每条分支有汇合或明确结局 | 无提示死局 |
| R-08 | 节奏可承受 | P1 | 读者能说出想继续/想停的位置 | 连续高强度或长时间无变化 |

## 3. 证据层级

从低到高：

1. 作者自读；
2. 编辑/同行读；
3. 目标读者读；
4. 多人试读 / 分支试玩。

结论优先使用高层证据；只有低层证据时，标“待验证”。

## 4. 提问脚本

只问，不解释；不辩护设计。

1. 这个故事讲什么？用一句话说。
2. 主角想要什么？为什么现在行动？
3. 哪里最想继续读？哪里想停？
4. 哪里不信？为什么？
5. 哪个选择/转折最有影响？改变了什么？
6. 有没有前后对不上的地方？
7. （分支）你走到哪个结局？觉得是应得的吗？

## 5. 判定规则

- 通过：P0 判据（R-01/02/03/06；分支剧本含 R-07）全部有证据；无未解决连续性冲突。
- 有条件通过：P0 基本成立，但 R-04/05/08 有明确行动项。
- 不通过：前提/动机/连续性任一不成立；或分支存在死局。

样本不足时写 `SKIP`，不算通过。
