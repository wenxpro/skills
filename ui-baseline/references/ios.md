# iOS 平台基线

## 1. 布局

- 使用安全区；底部主操作避开 Home Indicator。
- 首屏首屏内容不被 Dynamic Island/刘海遮挡。
- 触控目标不小于 44×44pt；相邻可点击元素留出间距。
- 优先系统导航与返回手势，不自造左上角返回。
- Sheet 使用系统 detent；不嵌套多层 Sheet。
- 小屏与 Pro Max 都验证；不用固定宽度假设。

## 2. 字体与 Dynamic Type

- 使用系统文本样式（largeTitle/title/body/callout/footnote 等）。
- 不写死字号；需要固定尺寸的图形/网格文字要设上限并说明原因。
- 支持到最大辅助字号；关键按钮与数值不被截断，内容可滚动。
- 长标题最多 2 行；列表项名称 1 行截断，详情可读全名。
- 中文回退到系统中文字体；MVP 不引入自定义字体。

## 3. 颜色与外观

- 使用语义色（背景/表面/文字/分隔线/强调/成功/警告/错误）。
- 浅色/深色都验证；不写死纯白/纯黑。
- 正文对比度 ≥4.5:1；大字号与图形 ≥3:1。
- 状态不只靠颜色，配文字/图标/数量。
- 尊重 Increase Contrast 与 Reduce Transparency。

## 4. 无障碍

- 每个交互控件有 label；复合卡片合并为一个可读元素。
- 需要时提供 traits/hint；朗读顺序与视觉顺序一致。
- 支持 VoiceOver 完成主路径：开始、返回、提交、取消。
- 支持 Switch Control / 全键盘访问的关键操作。
- 尊重 Reduce Motion：关闭非必要缩放/位移动画。
- 错误与成功状态可被屏幕阅读器播报。

## 5. 导航与系统表面

- NavigationStack 管层级；Modal 用于创建/编辑流程。
- 返回手势可用；取消需确认时会说明后果。
- PhotosPicker 选图，不申请完整相册权限。
- 保存图片使用 add-only 权限；拒绝后给说明与设置入口。
- 分享用系统 ShareLink；付费购买用 StoreKit 系统界面。

## 6. 触感与动效

- 勾选、保存、选择可给轻触感；错误不给愉悦反馈。
- 动画时长与曲线服从系统；不做循环装饰动画。
- 不在主流程加插屏、倒计时、抖动等压力型动效。

## 7. 检查表

- [ ] 安全区与 Home Indicator 处理正确
- [ ] 所有可点击元素 ≥44×44pt
- [ ] Dynamic Type 最大档主路径可完成
- [ ] 浅色/深色对比度通过
- [ ] VoiceOver 可完成主路径
- [ ] Reduce Motion 下无必要动画
- [ ] 系统导航/Sheet/权限弹窗符合 HIG
- [ ] 13 mini / 标准 / Pro Max 宽度不裁切
