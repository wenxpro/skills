# Web 平台基线

## 1. 结构与语义

- 使用语义 HTML：header/nav/main/section/footer、button/a、label。
- 一个页面一个 h1；标题层级不跳级。
- 图片有 alt；装饰图 alt 为空。
- 表单控件有关联 label；错误与字段关联。

## 2. 响应式与布局

- 移动优先；内容在窄屏不横向滚动。
- 断点按内容决定，不按设备型号；示例：单列 → 双列 → 三列。
- 触控目标不小于 44×44px；相邻目标留出间距。
- 固定高度容器改为自适应；长文本可换行。
- 200% 缩放不丢内容、不重叠。

## 3. 键盘与焦点

- 所有交互可用键盘完成。
- 焦点可见；不用 `outline: none` 去掉了事。
- Tab 顺序与视觉顺序一致。
- 提供 Skip to content。
- Esc 关闭浮层；Enter/Space 触发按钮。
- 焦点陷阱只用于模态；关闭后焦点回到触发元素。

## 4. ARIA 与屏幕阅读器

- 优先原生语义；ARIA 只补缺口。
- 动态状态用合适的 live region，不滥用。
- 图标按钮有 accessible name。
- 折叠/展开、Tab、菜单有对应角色与状态。
- 错误摘要可被朗读，且能定位到字段。

## 5. 颜色与字体

- 正文对比度 ≥4.5:1；大字号与图形 ≥3:1。
- 不只用颜色表达状态；配文字/图标。
- 支持浏览器字号放大与 200% 缩放。
- 不写死视口高度导致内容被截断。

## 6. 表单与错误

- 必填/可选标注清楚。
- 错误说明原因与修正方式；不只用红色边框。
- 提交中禁用重复提交并给反馈。
- 自动填充与密码管理器可用。
- 不把敏感信息写进 URL。

## 7. 动效与媒体

- 尊重 `prefers-reduced-motion`。
- 避免自动播放带声音的媒体。
- 视频有字幕/文字替代。
- 加载有骨架或进度，不用无限旋转遮罩。

## 8. 国际化与性能

- 文案进资源文件；不拼接句子。
- 预留文本膨胀空间；按钮不固定宽度。
- 图片用合适尺寸与格式；避免布局位移。
- 字体加载有回退；首屏不阻塞。

## 9. 检查表

- [ ] 键盘可完成主路径
- [ ] 焦点可见且顺序合理
- [ ] 对比度与 200% 缩放通过
- [ ] 表单错误可定位、可朗读
- [ ] 触控目标 ≥44×44px
- [ ] `prefers-reduced-motion` 生效
- [ ] 窄屏无横向滚动
