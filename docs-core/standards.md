# 文档槽位映射

本文件把 7 个槽位映射到具体编号/文件。其他团队可整体替换，`SKILL.md` 不受影响。

## Game（00~05、07；06 为可选遗留槽位，配合 game-docs）

| 槽位 | 文件 |
|---|---|
| 入口 | `00-README.md` |
| 假设 | `01-run-brief.md` |
| 规则 | `02-design-spec.md` |
| 验收 | `03-acceptance.md` |
| 决策 | `04-adr/` |
| 证据 | `05-reviews/`（试玩结论并入评审；`06-playtests/` 可选） |
| 检查 | `07-checklists/` |

## Software（PRD + 包 DESIGN.md）

| 槽位 | 文件 |
|---|---|
| 入口 | 设计总纲 / README |
| 假设 | PRD 4.x |
| 规则 | PRD + 各包 DESIGN.md |
| 验收 | 论证文档验证清单、验收编号（如 M1-M20） |
