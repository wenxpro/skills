# 音频目录与安全应用

> 适用于「音频文件 + 事件配置」由一份配置驱动的项目。具体文件名/总线名由项目规范给出。

## 1. 单一配置源

- 一份音频配置描述：事件 ID、文件路径、总线、音量、pitch、loop。
- 游戏代码与挑选/检视工具读同一份配置。
- 文件路径是显式白名单，不自动扫描、不猜。
- 配置变更走版本控制；生成候选不进正式目录。

## 2. 事件/文件树

| 检查 | 通过标准 |
|---|---|
| 缺失 | 事件无文件/文件无事件可查 |
| 共享 | 多事件共用文件有提示 |
| 未使用 | 文件未被事件引用 |
| 漂移 | 配置/文件 hash 不一致 |
| 已应用 | 草稿与正式配置分离 |

## 3. 安全应用

- 修改先进草稿：文件替换是文件级，参数是事件级。
- 应用前备份文件 + 配置 + lock。
- hash 漂移拒绝应用。
- 失败回滚。
- 支持撤销最近一次应用。
- 不改路径/ID/导入元数据，除非明确迁移。

## 4. 候选库

- 生成候选放独立目录，sidecar 记录来源/许可/seed。
- 候选不自动应用；人工试听后进草稿。
- 重开项目可继续试听。
- 清理策略明确，避免仓库膨胀。

## 5. 验证

- 配置 schema 校验
- 事件/文件树一致性
- 应用/撤销事务
- 游戏侧加载与播放
- 可访问性/视觉测试（如工具 UI）
- 跨项目 conformance（同一配置在工具与游戏里一致）
