# 音频总线与路由检查表

> 具体总线名、默认音量、音效文件由项目规范给出；本表只列结构与检查项。

## 1. 总线拓扑

| 检查 | 通过标准 |
|---|---|
| Master | 存在；最终输出 |
| 分组 | SFX/Music/Ambience/UI/Voice 按需 |
| 发送 | 分组发送到 Master，不循环 |
| 命名 | 代码、设置、测试一致 |
| 静音 | 主静音与分组音量独立 |
| 默认值 | 有明确默认音量，不靠运行时猜 |

## 2. 播放器路由

| 检查 | 通过标准 |
|---|---|
| 每个播放器 | 显式 `bus`，不依赖默认 |
| 2D/UI | 不参与 3D 衰减 |
| 3D | 衰减/距离/优先级明确 |
| 复用 | voice 池/复音上限明确 |
| 高频事件 | 冷却/最小间隔/优先级 |

## 3. 混音

| 检查 | 通过标准 |
|---|---|
| 单音 | 不削顶 |
| 多音 | 同时播放不爆音 |
| 关键提示 | 高于环境/音乐；必要时 ducking |
| 音乐 | 循环接缝无爆音 |
| 环境 | 不压过起手/命中提示 |
| 滑条 | 实时生效；0 与静音区分 |

## 4. 设置

| 检查 | 通过标准 |
|---|---|
| 键 | 与总线键一致 |
| 默认 | 缺文件/缺键可恢复 |
| 保存 | 只存用户偏好 |
| 应用 | 改值立即写 AudioServer |
| 测试 | 独立配置，不读真实用户配置 |

## 5. headless 与自动检查

| 检查 | 通过标准 |
|---|---|
| 音频节点 | headless 不创建 |
| 总线 | 断言存在与路由 |
| 播放器 | 断言 bus 名称 |
| 音量 | 断言线性/分贝转换 |
| 静音 | 断言主静音状态 |
| 失败 | 非零退出码 + 可定位输出 |

## 6. 主观证据

- 耳机/扬声器/不同音量
- 关键提示是否能从音乐/环境中辨出
- 连续战斗是否疲劳/刺耳
- 与画面 contact 是否同步（交 `game-feel`）
