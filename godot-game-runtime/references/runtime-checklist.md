# Godot 运行时检查表

> 用于工程集成与 headless 回归。阈值、命令、场景名由项目规范给出；本表只列检查项。

## 1. 工程配置

| 检查 | 通过标准 |
|---|---|
| 主场景 | `project.godot` 指向唯一主场景 |
| 窗口/拉伸 | 设计分辨率、窗口覆盖、stretch 模式有明确选择 |
| 渲染器 | 桌面/移动渲染路径与目标平台一致 |
| 音频总线 | 默认总线布局存在，分组命名与路由明确 |
| 自动加载 | 只放全局服务；不在自动加载里做场景逻辑 |
| 输入映射 | 键鼠/手柄/UI 导航都在同一处注册 |

## 2. 场景与职责

| 检查 | 通过标准 |
|---|---|
| 根节点 | 只做编排：角色、相机、HUD、音频、测试模式 |
| 战斗/表现 | 规则结算与动画/特效/HUD 不互相写状态 |
| 测试场景 | 薄壳或显式 CLI 模式，不复制工程配置 |
| 资源引用 | 相对路径 `res://`，无本机绝对路径 |
| 失败路径 | 缺节点/缺资源时显式错误或已文档化 fallback |

## 3. 输入

| 检查 | 通过标准 |
|---|---|
| 语义动作 | 移动/攻击/防御/暂停/调试各自独立 |
| 设备覆盖 | 键盘、手柄、UI 导航都有映射 |
| 死区 | 摇杆死区在输入层统一 |
| 焦点 | 菜单焦点链可循环，确认/返回不穿透战斗 |
| 断连 | 手柄断开/重连有可观察状态 |

## 4. AnimationTree

| 检查 | 通过标准 |
|---|---|
| 状态名 | 外部只依赖稳定状态名 |
| 参数路径 | 时间缩放/混合参数有统一设置入口 |
| 循环 | Animation 资源与状态节点都设置 loop |
| BlendTree | `output` 已连接，混合位置可读回 |
| 状态切换 | 同帧多请求有明确优先级 |
| 缺失 clip | 显式 fallback 或错误，不静默 T-pose |

## 5. 音频

| 检查 | 通过标准 |
|---|---|
| 总线 | Master + 分组 + 音乐/音效路由明确 |
| 播放器 | 每个播放器显式 `bus` |
| 音量 | 线性/分贝转换集中处理，滑条实时生效 |
| 静音 | 主静音与分组音量互不覆盖 |
| 持久化 | 只写用户偏好，读取有默认值 |
| headless | 不创建播放器，不依赖音频设备 |

## 6. 设置持久化

| 检查 | 通过标准 |
|---|---|
| 路径 | `user://`，不写项目目录 |
| 键 | 有默认值；缺键/缺文件可恢复 |
| 保存 | 失败可见；不静默吞错 |
| 测试 | 独立测试配置，不读真实用户配置 |
| 迁移 | 旧键删除/重命名有默认值兜底 |

## 7. headless 回归

| 检查 | 通过标准 |
|---|---|
| 启动 | 不依赖渲染/音频设备 |
| 时间 | 固定帧或固定步长，不靠墙钟 |
| 输出 | 成功/失败有稳定标记 |
| 退出码 | 失败非零；运行器检查退出码 |
| 隔离 | 每个用例独立进程或独立场景 |
| 证据 | stdout/stderr 保留，失败不覆盖旧证据 |

## 8. 截图

| 检查 | 通过标准 |
|---|---|
| 模式 | 窗口模式，不用 headless |
| 分辨率 | 截图前设置目标尺寸，记录实际输出尺寸 |
| 状态 | 角色/战斗/UI 状态固定 |
| 等待 | 至少等待渲染帧与布局帧 |
| 布局 | 多分辨率都跑边界/重叠断言 |
| 命名 | 分辨率/状态/版本可追溯 |

## 9. 导入与资源

| 检查 | 通过标准 |
|---|---|
| `.uid` | 由引擎生成，不手改 |
| `.import` | 由导入器生成，不手改 |
| 缓存 | 不入库；清理后能重建 |
| 二进制资产 | 许可证允许才入库；本地实验资产隔离 |
| 外部路径 | 不写本机绝对路径 |

## 10. 失败排查顺序

1. 先看退出码与 stderr，不先看截图
2. 再看场景/节点路径与资源是否存在
3. 再看 InputMap、总线、AnimationTree 参数路径
4. 最后才怀疑引擎版本/渲染器/硬件
