# 选择与状态模型

## 1. 选择节点

| 字段 | 要定义 |
|---|---|
| ID | 稳定、可本地化 |
| 触发 | 何时出现、谁在场、前置条件 |
| 选项 | 每个选项的代价/收益/信息 |
| 写入 | 选择后改变哪些状态 |
| 读取 | 哪些后续内容依赖它 |
| 可见性 | 玩家/角色/系统各自知道什么 |
| 可逆 | 是否可补救/回滚 |

## 2. 状态字段

| 类型 | 例子 | 注意 |
|---|---|---|
| 标记 | 帮过/骗过/见过 | 不要散落布尔 |
| 计数 | 信任/怀疑/金币/次数 | 上下限、衰减 |
| 关系 | 角色态度/阵营 | 双向变化 |
| 物品 | 真货/假货/钥匙 | 唯一性/消耗 |
| 知识 | 知道真相/见过证据 | 与玩家知识区分 |

要求：

- 默认值明确
- 生命周期/清理规则明确
- 变更日志可用于回放/QA
- UI 不直接推断状态

- 没有只读不写的条件
- 选项之间有真实取舍
