# 构筑与内容池

## 1. 构筑轴

| 轴 | 例子 | 取舍 |
|---|---|---|
| 伤害类型 | 直伤/持续/爆发 | 稳定 vs 峰值 |
| 射程 | 近/远 | 安全 vs 输出 |
| 节奏 | 快/慢 | 灵活 vs 重击 |
| 生存 | 护盾/闪避/回复 | 容错 vs 输出 |
| 召唤/控制 | 宠物/减速 | 间接 vs 直接 |
| 资源/风险 | 消耗/过热/贪心 | 上限 vs 稳定 |

要求：

- 至少两条轴产生不同打法
- 选项有取舍，不是纯上位替代
- 流派可识别，但不逼背最优解

## 2. 内容池

| 字段 | 要定义 |
|---|---|
| ID | 稳定 |
| 类型 | 武器/升级/进化/事件 |
| 权重 | 基础权重/条件权重 |
| 前置 | 等级/角色/组合/事件 |
| 互斥 | 不能同时出现 |
| 上限 | 最多几个/唯一 |
| 转化 | 满级/满槽后 |

- 内容表单一事实源，代码不写死
- 池子随进度/角色变化，可解释
- 避免海量低质填充

## 3. 进化/转化

| 项 | 要定义 |
|---|---|
| 条件 | 等级/组合/事件 |
| 分支 | 路线/互斥 |
| 次数 | 一次性/可重复 |
| 变化 | 玩法/数值/表现 |
| 可读性 | 玩家如何知道条件 |

进化应改变玩法，不只是数值放大；没有进化也能赢，但有不同路线。

## 4. 随机与公平

- 种子可复现
- 极端组合有兜底，不产生无解局
- 重随/ban/pick 规则明确
- 难度档改压力，不偷偷改规则
- 记录种子/构筑/结果

## 5. 证据

- 构筑矩阵：流派/组合可行性
- 内容覆盖：每个选项被选/跳过/有效
- 跑批：胜率/时长/分布
- 试玩：选择感/想再来
