# Roguelite 单局结构

## 1. 单局形状

| 阶段 | 目的 | 要定义 |
|---|---|---|
| 开局 | 建立起点/角色/初始选择 | 初始强度、可选路线 |
| 成长 | 构筑形成 | 奖励频率、选择密度 |
| 峰值 | 压力/精英/Boss | 难度曲线、检查点 |
| 收束 | 胜负/结算 | 终局条件、重开 |

要求：

- 目标时长与失败条件明确
- 至少一个「变强」时刻和一个「取舍」时刻
- 单局太长会疲劳；用时长分布验证

## 2. 奖励节奏

| 项 | 要定义 |
|---|---|
| 频率 | 每次战斗/每层/每几分钟 |
| 稀有度 | 普通/稀有/传说权重 |
| 保底 | 多久必出某类 |
| 重随 | 次数/成本/限制 |
| 满级 | 满级/满槽后的转化 |

检查：

- 没有空奖励
- 每次至少一个当前有用/一个长期投资
- 奖励与构筑协同，但不是唯一组合

## 3. 失败与重开

- 死亡→重开时间
- 结算信息：构筑、关键选择、死因、Boss TTK
- 失败是否带来新信息/新选择
- 是否可跳过过场

## 4. 证据

- 种子化跑批：胜率、时长、构筑分布
- 奖励选择率：哪些被选/跳过
- 试玩：是否想再来
- 反例：每局同一套 → 构筑/内容失败
