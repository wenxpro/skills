# 06 试玩记录

> 文档编号：**06 · 试玩记录**

## 何时记录

- 灰盒第一次能完整跑一局
- 每次加入会改变体验的内容
- 里程碑评审前

## 命名

```
0001-YYYY-MM-DD-场景.md
```

## 模板

复制 [0000-playtest-template.md](0000-playtest-template.md)，按日期命名。

## 原则

1. **不要教玩家。** 先观察 30 秒，再回答必要问题。
2. **只问行为，不问喜好。** 「你刚才为什么往左走」比「你觉得好玩吗」有用。
3. **记录原话。** 不要只写「体验良好」。
4. **一次只改一个变量。** 试玩后不要同时改 5 个地方。
5. **5 人起步。** 少于 5 人，结论通常是噪音。

## 试玩后输出

- 3 条观察
- 3 条问题
- 3 条行动（对应 Spec / 验收 ID）
- 是否达到止损条件
