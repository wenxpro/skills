## 1. 用例格式

| 列 | 含义 |
|---|---|
| ID | `AC-<类别>-<序号>`，与 Spec 的规则 ID 对应 |
| 优先级 | P0 / P1 |
| 前置 | 状态、种子、数量、场景 |
| 操作 | 玩家或测试者做什么 |
| 预期 | 可观察、可判定的结果 |

**写验收的标准：**

- 不写「手感好」「看起来正常」
- 写数字、状态、时间、数量
- 一条用例只验证一件事
- P0 覆盖核心循环和必须修的错误

## 2. 类别

| 类别 | 前缀 | 覆盖 |
|---|---|---|
| 状态机 | `AC-STATE-` | 启动、暂停、升级、死亡、重开 |
| 输入 / 移动 | `AC-INPUT-` | 键位、归一化、UI 拦截 |
| 核心交互 | `AC-SYS-` | 攻击 / 任务 / 技能 |
| 敌人 / 挑战 | `AC-ENM-` | 行为、伤害、死亡 |
| 生成 | `AC-SPWN-` | 时间、上限、位置、种子 |
| 进度 / 升级 | `AC-XP-` / `AC-UPG-` | 经验、升级、能力效果 |
| UI / 结算 | `AC-UI-` | HUD、选择、结算、可读性 |
| 性能 / 日志 | `AC-PERF-` / `AC-LOG-` | FPS、卡顿、日志、复现 |
| 边缘情况 | `AC-EDGE-` | 同帧冲突、溢出、满级、失焦 |
