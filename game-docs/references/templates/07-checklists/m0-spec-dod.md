# M0 规范完成定义（DoD）

> 里程碑：立项 / 规范
> 目标：在写代码前，确认「这一局是什么」和「怎么验收」

## 必须完成

- [ ] `01-run-brief.md` 填完：一句话、单局参数、核心循环、灰盒范围
- [ ] `02-design-spec.md` 覆盖当前里程碑：状态、输入、核心系统、UI、性能、边缘情况
- [ ] 每条 P0 行为都有规则 ID
- [ ] `03-acceptance.md` 每条 P0 规则都有对应用例
- [ ] 关键方向 / 架构决策有 ADR，状态为 `Accepted`
- [ ] 6 人评审完成：签字表、行动项、结论齐全
- [ ] 评审行动项全部关闭
- [ ] 本地链接检查通过
- [ ] 没有残留占位符或「待填」标记
- [ ] 范围明确：Non-goals 写清楚

## 可以不做

- 完整数值平衡
- 全部内容清单
- 最终美术 / 音频
- 技术方案（TDD）的全部细节

## 退出条件

以上检查全部通过，且评审结论为「通过」或「有条件通过且条件已关闭」。

## 不通过怎么办

- 缺玩法定义 → 回到 01
- 缺行为规则 → 回到 02
- 缺验收 → 回到 03
- 方向不成立 → 写新 ADR，不要硬推
