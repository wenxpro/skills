# 文档自检清单

> 在评审前（`review` skill + game profile），由文档维护者自检。每项必须能回答「是 / 否 + 证据」。

## 1. 结构

- [ ] 所有根文档有两位编号
- [ ] 新增文档使用新编号，没有复用旧编号
- [ ] ADR 使用 `0001-主题.md`
- [ ] 评审使用 `0001-日期-主题.md`
- [ ] 试玩使用 `0001-日期-场景.md`
- [ ] 所有本地链接可解析

## 2. 内容

- [ ] 01 的一句话能说清「玩家做什么、为什么再来一局」
- [ ] 01 有明确的 Non-goals
- [ ] 02 只覆盖当前里程碑，没有提前写未来内容
- [ ] 02 每条规则有 ID
- [ ] 02 的规则可判定，不写「手感好」
- [ ] 02 定义了失败、重开、暂停
- [ ] 02 定义了边缘情况
- [ ] 03 每条 P0 规则都有对应用例
- [ ] 03 的预期可观察、可判定
- [ ] 03 标注了 P0 / P1

## 3. 一致性

- [ ] 01 的时长 / 失败条件与 02 一致
- [ ] 02 的规则 ID 与 03 的验收 ID 能对应
- [ ] 关键决策有 ADR，且状态正确
- [ ] ADR 记录了备选方案与否决理由
- [ ] 评审行动项有负责人和截止
- [ ] 文档版本 / 日期已更新

## 4. 范围

- [ ] 当前里程碑没有「多角色 / 多地图 / Boss / Meta」等后置内容
- [ ] 没有为了模板保留不适用的章节
- [ ] 没有残留占位符或「待填」标记
