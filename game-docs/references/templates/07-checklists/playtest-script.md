# 5 人试玩脚本

> 目标：验证「是否易懂、是否想再来、是否有变化」，不是收集「好不好玩」。
> 时长：每人 15~20 分钟。

## 1. 准备

- [ ] 构建可运行，无阻断 bug
- [ ] 固定种子或不固定，记录清楚
- [ ] 录屏 / 记录表
- [ ] 不提前讲解玩法
- [ ] 准备 3 个问题，不增加

## 2. 开场（30 秒）

只说三句：

1. 这是一个 3 分钟的试玩。
2. 我不会教你，遇到问题请直接说。
3. 死了也没关系，随时可以重开。

不要说：「这个游戏是……」「你应该先……」。

## 3. 观察（前 3 分钟，不打断）

记录：

- 第一次按键用了多久
- 是否知道自己在做什么
- 第一次死亡是否明白原因
- 第一次升级是否比较选项
- 是否主动重开

## 4. 提问（只问 3 个）

1. 刚才 30 秒内，你知道自己要做什么吗？
2. 死了以后，你想不想再来一局？为什么？
3. 这一局和上一局，哪里不一样？

追问原则：

- 问行为，不问喜好
- 问「刚才为什么…」，不问「你觉得…」
- 不辩护、不解释设计
