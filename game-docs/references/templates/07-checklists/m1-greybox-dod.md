# M1 灰盒完成定义（DoD）

> 里程碑：灰盒
> 目标：证明「核心循环是否成立」，不追求内容量

## 必须完成

- [ ] 一局能从头玩到尾：开始 → 核心交互 → 失败/胜利 → 重开
- [ ] 单局时长符合 01 的设定（允许 ±20%）
- [ ] `03-acceptance.md` 所有 P0 用例通过
- [ ] 5 名外部试玩完成，记录在 `06-playtests/`
- [ ] 试玩者中 ≥ 3 人愿意主动再开一局
- [ ] 无阻断性 bug
- [ ] 性能基线记录：机型、FPS、同屏上限、卡顿
- [ ] 固定种子可复现
- [ ] 日志包含种子、结果、统计、选择记录
- [ ] `02-design-spec.md` 已根据实现更新
- [ ] `03-acceptance.md` 已更新执行记录
- [ ] M1 6 人评审完成，行动项关闭

## 可以不完成

- P1 用例
- 最终美术 / 音效
- 8 分钟 / Boss / 多角色
- Meta / 存档 / 商店

## 退出条件

P0 全过 + 试玩达标 + 评审通过 → 进入 M2。
否则：先改循环，不要加内容。

## 止损问题

- 5 人中 < 3 人想再来一局
- 玩家说不出两局差异
- 不需要操作也能赢
- 所有选择都只是数值 +10%
- 3 分钟内没有紧张时刻
