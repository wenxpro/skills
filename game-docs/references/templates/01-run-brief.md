## 1. 一句话

> 用一句话说清：玩家在多少分钟里、做什么、为什么想再来一局。

[示例] 8 分钟里，你只负责走位，武器自动开火；靠三选一把弱武器变成清屏机器。

## 3. 核心循环

```
行动 → 反馈 → 收益 → 选择 → 变强
  ↑                          ↓
  └──── 重开 ← 失败/胜利 ────┘
```

三个时间尺度：

| 尺度 | 玩家在做什么 | 设计目标 |
|---|---|---|
| 3 秒 | 最小操作循环 | 手感 |
| 30 秒 | 一次有意义的选择 | 节奏 |
| 一局 | 完整 Build | 重玩 |

## 4. 第一个灰盒

**只做这些：**

- 1 个场景 / 竞技场
- 1 个角色 / 单位
- 1 种核心交互（攻击 / 任务 / 移动）
- 1 种敌人 / 挑战
- __ 个升级 / 选择
- 失败与重开
- __ 分钟计时

**明确不做：**

- 多角色 / 多武器 / 多地图
- Boss
- Meta / 商店 / 存档
- 剧情 / 主题 / 美术
- 完整音效

## 5. 验证问题

找 5 名试玩者，只问：

1. 30 秒内是否理解操作？
2. 死后是否想再来一局？
3. 能否说出这局和上局的不同？
4. 是否有至少一个选择改变了打法，而不只是数值？

## 6. 止损条件

满足任意一条，先改循环，不要加内容：

- 5 人中少于 3 人想再来一局
- 玩家说不出两局差异
- 玩家不需要操作也能赢 / 活
- 所有选择都只是 +10%
- 3 分钟内没有任何紧张时刻
