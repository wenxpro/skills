# 动画失败模式

> 每条按「现象 / 根因 / 先查什么 / 修复方向」记录。示例只说明模式，不是项目规则。

## 1. 反向脚 / 反向剑

**现象**：角色前进但脚面朝后；剑刃从手背穿出。

**根因**：

- 资产前方轴与引擎前方轴不一致，适配层旋转次数不统一
- 骨骼 roll/缩放导致挂点继承错误轴向
- 几何直接挂 BoneAttachment，继承骨骼局部轴

**先查**：

1. 视觉根朝向是否只转一次
2. Foot/Toe/Hand 的世界位置与朝向
3. 武器挂点的局部轴与长度

**修复方向**：

- 统一适配层朝向
- 骨骼只提供位置，几何朝向由代码定义
- 武器用显式握把/指尖方向，而不是无条件继承手骨 roll

## 2. 浮空 / 穿地

**现象**：待机脚底离地；走跑支撑脚陷地；倒地时身体穿过地板。

**根因**：

- 只有出生时一次全局 offset
- Hips Y 缺失但用视觉根硬补
- 只采样一只脚或只采样脚，不采样身体接触点

**先查**：

1. 每个 clip 的最低脚底曲线
2. 支撑相/离地窗口
3. 倒地/起身的身体接触点

**修复方向**：

- 逐帧脚底 clamp 或 per-clip ground curve
- 倒地用 Hips/Head/Hand 接触点
- 记录残差与失败帧

## 3. 滑步 / 步幅不匹配

**现象**：走跑时脚像在冰面滑；慢走像快跑。

**根因**：

- 动画自然速度与实际移动速度不一致
- 只改位移速度，不改动画播放速率
- 前进误用反向 clip

**先查**：

1. clip 的自然速度（脚间距 / 周期）
2. 本地前向轴
3. 播放速率是否随速度缩放

**修复方向**：

- 用实际速度 / clip 自然速度缩放
- 明确前进/后退 clip
- 用侧视或脚底采样验证

## 4. 循环停末帧

**现象**：Idle/Walk 播一次就停；状态机还在 loop。

**根因**：

- 只设 AnimationNode 的 loop，没有设 Animation 资源的 loop
- BlendTree 没有连接 output

**先查**：

1. 资源 loop mode
2. 状态节点 loop mode
3. BlendTree output 连接

**修复方向**：

- 资源与状态同时设置 loop
- 连接 output，读回混合位置/播放位置

## 5. 重定向后动作变形

**现象**：攻击横躺、走路站直、手部扭曲。

**根因**：

- 骨骼命名/层级/roll 不匹配
- 缩放未 Apply、非均匀缩放
- 只映射旋转，不检查 Hips/脚底/武器骨

**先查**：

1. 必需骨骼是否齐全
2. 轨道数与关键帧数
3. Hips 高度与脚底最低点
4. 手骨/武器骨方向

**修复方向**：

- 先修资产/重定向，不要用 IK/offset 掩盖
- 缺失 clip 显式 fallback
- 用 contact sheet + 固定步长断言验证

## 6. 接触帧漂移

**现象**：按键/起手瞬间就扣血；或剑已穿过身体但伤害晚到。

**根因**：

- 伤害在输入/起手结算，而不是 contact 事件
- 动画事件与玩法计时器各算一套
- 固定步长下计时器浮点边界多算一帧

**先查**：

1. 接触事件的唯一事实源
2. 固定步长下的实际帧 vs 期望帧
3. 动画过渡是否吞掉首尾帧

**修复方向**：

- 统一 contact 事件
- 固定步长审计，记录差值
- 计时器到 0 的判定加显式容差

## 7. 没有 strafe/turn clip 却做八方向

**现象**：侧移时脚仍朝前，像横向滑；转身像原地旋转。

**根因**：

- 资产没有对应 clip
- 用前进 clip 硬套侧移
- 根节点朝向与视觉朝向混在一起

**先查**：

1. 资产是否真有 strafe/turn clip
2. 根节点朝向优先级
3. 视觉根偏航/侧倾是否回到中性

**修复方向**：

- 有 clip 就用 clip；没有就明确标注近似
- 根节点锁目标 + 视觉根偏航/侧倾
- 转身用 stepping turn 并匹配播放速率
