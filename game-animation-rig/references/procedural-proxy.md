# 程序化低模代理

> 当蒙皮/骨骼轴向不可信、或正式角色资产未到位时，用骨骼位置驱动低模代理。目标是可读与可验证，不是最终美术。

## 1. 适用条件

- 骨骼缩放/roll/坐标轴不可信，直接挂几何会反向/穿模
- 正式 mesh 未定，但需要验证移动/攻击/受击剪影
- 需要稳定的脚/面罩/武器朝向
- 需要低成本多角色/Boss 配色

不适用：

- 最终角色外观验收
- 需要写实面部/布料/毛发
- 需要蒙皮形变表现

## 2. 代理规则

| 项 | 规则 |
|---|---|
| 骨骼用途 | 只读关节世界位置；不把身体几何挂 BoneAttachment |
| 朝向 | 头/髋/脚只用视觉根局部前向；不继承骨骼 roll |
| 脚 | 脚块平放；底面由脚骨 Y 与 sole offset 计算并 clamp |
| 武器 | 握把在 Hand；刀刃方向用 Hand→Index；不继承 hand roll |
| 材质 | 身体色 + 装甲/暗金属/皮革分层；受击闪白仍生效 |
| 比例 | 强剪影优先；头/肩/武器在最小分辨率可辨 |
| 护甲 | 部件走同一位置系统；不改变脚底/武器/碰撞 |

## 3. 护甲化

- 头盔帽檐、胸甲、肩甲、护臂、护胫、膝甲、腰带、腿甲、靴头
- 装甲材质与角色色混合，保留阵营区分
- 方形/低段数球体优先；避免高面数
- 护甲是剪影信息，不是碰撞体

## 4. 失败模式

- 几何挂 BoneAttachment 后脚/剑继承错误轴向
- 代理几何穿地/浮空：脚底 clamp 未覆盖代理
- 护甲遮住面罩/武器剪影
- 代理比例与碰撞体不一致，导致攻击距离误判
- 用代理外观宣称正式美术完成

## 5. 验证

- contact sheet：idle/攻击/移动/倒地
- 侧视：脚底、膝盖、武器
- 空间/死亡测试：脚底/身体接触点
- 多分辨率：剪影仍可辨
- 明确标注「代理/占位」，正式资产替换时保持事件/挂点不变
