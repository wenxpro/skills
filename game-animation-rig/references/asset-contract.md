# 角色资产与重定向检查表

> 本表是结构检查；具体容差、采样率、帧率、单位换算由项目规范给出。

## 1. 资产合同

| 项 | 要写清 | 失败后果 |
|---|---|---|
| 单位 | 1 unit 对应多少米 | 身高/步幅/武器长度全错 |
| 朝向 | 资产前方轴；引擎前方轴；适配层只转一次 | 反向脚/反向剑/背对目标 |
| 原点 | 双脚脚底中心还是骨盆中心 | 浮空/穿地/相机偏移 |
| 缩放 | armature/mesh scale 是否已 Apply | 非均匀缩放、骨骼全局缩放 |
| 骨架 | 必需骨骼、命名、层级、roll 约定 | 重定向轨道错位 |
| 接触点 | Foot/Toe 标记；身体接触点 | 脚底/倒地 clamp 失效 |
| 武器 | 握把原点、轴向、长度、握把偏移 | 刀穿手/枪尖穿地 |
| 材质/贴图 | 材质槽、颜色空间、透明模式 | 剪影/受击闪白异常 |

## 2. 导入与重定向

| 检查 | 通过标准 |
|---|---|
| 采样率 | 动画采样满足项目要求，不稀疏 |
| 关键帧 | 导出不简化关键帧；插值类型可解释 |
| 轨道数 | 每个 clip 的骨骼轨道数量合理 |
| Hips Y | 有垂直位移曲线；缺失必须记录 |
| 首尾 | 循环 clip 首尾差在项目容差内 |
| 缩放轨道 | 无非 1.0 缩放轨道 |
| 命名 | 无重复后缀/重复 clip |
| 武器骨 | 手骨/手指骨存在且方向可验证 |
| 缺失 clip | 显式 fallback 或错误 |

## 3. 地面接触

| 状态 | 接触点 | 检查 |
|---|---|---|
| 待机/走跑 | Foot/Toe | 最低脚底逐帧采样，支撑相不滑 |
| 起手/收招 | Foot/Toe | 脚底不穿地，允许的抬脚窗口写清 |
| 翻滚/跳跃 | 按 clip | 允许离地；落地帧不穿地 |
| 倒地/起身 | Hips/Head/Hand | 身体接触点 clamp，不只看脚 |

输出：

- 每个 clip 的 `ground_curve[time]` 或逐帧 clamp 方案
- 最低脚底、Hips 高度、首尾差的最小/最大值
- 失败帧号与对应 clip/时间

## 4. 状态机

| 检查 | 通过标准 |
|---|---|
| 状态名 | 稳定、可读、外部只依赖这些名字 |
| 循环 | 资源 loop 与状态 loop 一致 |
| 混合 | BlendTree 有 output；混合位置可读回 |
| 时间缩放 | 有统一参数路径；速度变化不改变规则时长 |
| 自定义时间轴 | 定格段/播放段/被截断段写清 |
| 优先级 | 死亡/受击/攻击/移动的覆盖顺序明确 |
| Fallback | 缺 clip 时走显式状态，不静默 T-pose |

## 5. 接触事件

| 检查 | 通过标准 |
|---|---|
| 事实源 | 动画事件或玩法计时器只有一个权威 |
| 固定步长 | 用固定 tick 断言接触帧 |
| 视觉验证 | 定格/录屏检查剑刃/武器接触 |
| 浮动边界 | 计时器到 0 的判定有显式容差 |
| 失败证据 | 记录实际帧、期望帧、差值 |

## 6. 移动与转身

| 检查 | 通过标准 |
|---|---|
| 本地前向 | 前进/后退轴写清 |
| 步幅 | 实际速度 / clip 自然速度缩放 |
| 反向 clip | 只用于后退，不用于前进 |
| 侧移 | 有 strafe clip 或用视觉偏航近似并标注 |
| 转身 | stepping turn 或专用 clip；转身不位移 |
| 锁定 | 根节点朝向与视觉偏好的优先级明确 |
| 中性回位 | 停止/攻击/格挡时视觉偏移回零 |

## 7. 证据

- 资产 contact sheet：朝向、剪影、武器
- 侧视图：腿部、脚底、膝盖
- 固定步长断言：接触帧、脚底误差、循环
- 录屏/试玩：连续观感、滑步、转身
