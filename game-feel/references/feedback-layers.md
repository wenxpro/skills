# 反馈分层与预算

> 本表只定义层与检查项；具体时长、幅度、帧数由项目规范填写。

## 1. 事件层

| 层 | 时间原点 | 主信号 | 辅助信号 | 不该做 |
|---|---|---|---|---|
| 起手/预告 | 攻击开始 | 姿态/颜色/音效 | 武器轨迹起点 | 提前扣血、遮挡剪影 |
| 接触 | contact 帧 | 命中闪白/命中音 | 火花、震动 | 改变伤害/判定 |
| 冲击 | contact 后短窗 | hitstop/震屏 | 音效尾、trail | 连续满强度、拖长 |
| 收招/余波 | 冲击后 | 恢复姿态/余音 | 镜头回落 | 拖到看不清下一次起手 |

## 2. 事件预算表

| 字段 | 要定义 | 备注 |
|---|---|---|
| 事件 | 轻击/重击/防御/破防/处决/特殊交互 | 同类一致 |
| contact 帧 | 规则接触帧 | 唯一事实源 |
| hitstop | 时长、影响对象 | 不改变规则 |
| 震屏 | 幅度、频率、衰减、恢复 | 不改看向点 |
| 闪白 | 帧数、颜色、对象 | 不遮起手 |
| trail | 长度、生命周期、颜色 | 不遮 UI |
| 音效 | 文件/合成、音量、总线 | 可静音 |
| 震动 | 强弱、时长、冷却 | 可关闭/降强度 |
| 优先级 | 同帧覆盖顺序 | 由项目定义；同帧只保留最高权重主信号 |
| 证据 | 断言/录屏/试玩 | 分层记录 |

## 3. 可读性检查

- 灰度下能区分攻击类型
- 静音下能靠姿态/颜色/剪影判断
- 闪白不遮武器轨迹
- 震屏不遮 UI/起手
- 连续命中不产生频闪/噪音
- 反馈强度不掩盖下一次起手

## 4. 验证

| 层 | 方法 | 能证明 | 不能证明 |
|---|---|---|---|
| 规则时序 | 固定步长断言 | contact 帧、反馈触发时机 | 视觉观感 |
| 静态 | contact sheet/定格 | 剪影、朝向、遮挡 | 连续节奏 |
| 动态 | 高帧率录屏 | 视觉接触、震屏、闪白 | 主观手感 |
| 真人 | 试玩 | 理解、爽感、疲劳 | 规则正确性 |

## 5. 可访问性

- 震屏强度/关闭
- 闪白强度/关闭
- 音量/静音分组
- 不依赖单一颜色/声音
- 高对比/字号由 `ui-baseline` 负责
